# Sistema de Gestão Corporativa e Análise de Projetos

Este projeto foi desenvolvido como um trabalho prático proposto pela professora do curso de Engenharia da Computação. Trata-se de uma aplicação em terminal (CLI) focada no estudo prático de estruturas de dados avançadas e análise de complexidade algorítmica. O sistema simula um ambiente de auditoria e gerência para o controle de cronogramas, salários e eficiência de projetos corporativos.

## 🚀 Conceitos Computacionais Aplicados
* **Estruturas de Dados Customizadas:** Uso de Programação Orientada a Objetos (Classes) para modelagem de entidades complexas (Empregados e Projetos).
* **Algoritmos de Ordenação Customizados:** Implementação manual (sem uso de funções nativas de ordenação) de métodos como:
  * *Bubble Sort* ($O(n^2)$) para filtragem decrescente de folhas salariais.
  * *Merge Sort* ($O(n \log n)$) para ordenação de investimentos financeiros de grande escala.
  * *Insertion Sort* e *Selection Sort* para tratamento de cronogramas atrasados e bônus em ordem alfabética.
* **Otimização de Consultas:** Uso de *Busca Binária* ($O(\log n)$) para localização instantânea de registros funcionais em vetores previamente ordenados.
* **Tabela Hash Estática:** Implementação manual de dicionários com tratamento de colisões por sondagem linear para indexação rápida de credenciais de gerência.

## 🛠️ Tecnologias Utilizadas
* Python 3
* Biblioteca nativa `datetime` (Manipulação de prazos e intervalos de tempo)
